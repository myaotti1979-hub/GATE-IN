# GATE IN ビューア（見るだけ）

家のパソコンの GATE IN が Google ドライブ（`GATEIN_data/view`）に置いた写しを、スマホや PC2 から見るだけの PWA です。
買う・設定を変えることはできません。ID・パスワード・残高はドライブに置かれないので、この画面にも出ません。

## 1. Google の設定（最初に1回）
1. https://console.cloud.google.com/ で新しいプロジェクトを作る（例：gatein-viewer）
2. 「API とサービス」→「ライブラリ」→ **Google Drive API** を有効にする
3. 「OAuth 同意画面」
   - ユーザーの種類：**外部**、公開ステータス：**テスト中** のままにする
   - スコープ：`.../auth/drive.readonly`（ドライブの読み取りのみ）
   - テストユーザー：**自分の Google アカウントだけ**を追加
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - 種類：**ウェブ アプリケーション**
   - 承認済みの JavaScript 生成元：`https://<GitHubのユーザー名>.github.io`
5. 表示されたクライアント ID を `config.js` の `clientId` に貼る（秘密の情報ではありません）

## 2. GitHub Pages に置く
リポジトリ（例：`gatein-viewer`）にこのフォルダの中身をそのまま置き、Pages を有効にする。
`https://<ユーザー名>.github.io/gatein-viewer/` を開いて「ホーム画面に追加」。

## 3. 使い方
- 初回だけ Google のログインと「ドライブの読み取り」の許可を求められます（テスト中の表示が出ます）。
- 表示：家のPCが動いているか／今日買った馬券と結果・収支／直近の収支／反省会／自動投票の設定。
- データは家のPCの写しなので、数十秒〜数分遅れることがあります。
